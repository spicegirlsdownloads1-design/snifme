JSON, images, visual fingerprints & tiled viewer inspector

This DevTools component inspects JSON structures or image-response metadata only when the Trufflehog capture and the optional JSON shapes or Verify image bytes / Enable visual fingerprints switch are enabled in the main dashboard.

Keep DevTools open on the original website and reload or browse normally. For images (up to 4 MiB), recorded data may include exact encoded dimensions for supported image formats, byte count and SHA-256 hash. The image bytes themselves are never stored. JSON schemas store field paths and types, not values.

Return to the Trufflehog dashboard to see the JSON shapes, Coverage Status, Images, Variant families and Cross-CDN matches views.

For v2.6, enable Inspect viewer manifests in the dashboard to summarise technical metadata from IIIF info.json, DZI, or Zoomify ImageProperties.xml responses that the original page has already requested. No additional URLs are fetched and no manifest bodies are retained.
